# Site Folha's Film's

Site da Folha's Film's (insulfilm, som e plotagem em Contagem/MG). Feito com Vite + React.

## Rodar no computador

```
npm install
npm run dev
```

## Publicar no Cloudflare Pages

- Framework preset: **Vite** (ou "None")
- Build command: `npm run build`
- Build output directory: `dist`
- Variável de ambiente (se pedir): `NODE_VERSION` = `22`

Fotos ficam em `src/assets/fotos/`, vídeos em `public/videos/` e todos os textos em `src/data.js`.
